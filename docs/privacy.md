# 隐私与 AI 边界

手动流程在浏览器中解析 CSV、通过 Web Worker 整理并生成导出包，不上传原始行。应用没有数据持久存储、分析脚本或自动保存。刷新即清空工作区。托管服务仍可能保留正常访问日志。

启用 AI 时，浏览器向同源 `/api/plan` 提交 API key、目标、当前方案、表 ID、文件名、列名、行数及逐列汇总计数；没有单元格值或示例行。字段名和自由文本也可能包含敏感信息，请查看界面的发送预览。

接口仅向固定的 `https://api.deepseek.com/chat/completions` 转发，key 放入认证头。应用代码不记录 key、不写入数据库或浏览器持久存储，不把它放入模型提示词或导出包。key 仍经过本站托管服务和 DeepSeek；敏感场景可选择本地运行或手动模式。

模型只提出限定 JSON 方案。结构和字段引用校验失败最多再尝试一次；单次请求超时 55 秒，并限制请求和响应大小。接口不会回显上游错误原文。方案不支持执行代码、任意 SQL、URL 或文件路径。用户应用后仍需复核并点击运行。

结构合法不代表经济含义正确。模型仍可能选错键、保留方式或误读目标；提示词也不能彻底消除字段名中的提示注入。有限操作与用户复核共同降低风险。

当前 AI 测试使用模拟响应，覆盖格式修复、字段约束、错误处理、次数上限与避免密钥回显。没有真实付费 API 调用验收，也不声称真实研究任务上的准确率。官方接口变化后可能需要调整模型名与参数。

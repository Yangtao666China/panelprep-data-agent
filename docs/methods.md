# 处理语义与验收

## 导入与键

单元格以字符串或 null 保存，不自动把 `0012` 转成 `12`。分隔符支持逗号、制表符和分号；支持引号内的分隔符、双引号和换行。重复或空白表头、非法引号、列数不一致均报错。表头去除首尾空格；真正的空白逻辑记录跳过，全空字段记录保留。

来源记录号从 1 开始，包含表头和跳过的空白记录；引号内换行不增加逻辑记录号。它不是物理行号。

复合键按有序字符串元组编码。任一键为 null 或空字符串时，该组永不匹配。未去空格时 `A` 和 `A` 不同。导入的文件 ID 根据原始字节摘要生成，相同文件重导入可复用方案；重复上传同一文件会增加后缀。

## 清洗顺序

1. 按选定列去首尾空格。
2. 空字符串及明确缺失标记转为 null，区分大小写。
3. 执行明确倍数换算，非法非空数值阻止整体导出。
4. 若选中，删除所有列值完全相同的记录，保留第一条的位置并合并全部原始来源号。

换算使用十进制整数系数，不把输入值先转成浮点数。倍率由 JSON 数值提供，以其十进制字符串为准，不能恢复倍率输入本身已损失的精度。倍率为正且不超过 1e12；输入有效数字和指数有资源上限。Python 使用 Decimal 独立计算。

## 连接与样本变化

每张辅助表最多使用一次，顺序连接。多对一检查右侧所有非空键唯一；一对多检查当前左侧唯一；一对一检查两侧。包含未匹配的键，重复也会阻止运行；缺失键不参与分组。

保留左侧顺序；一对多按右侧原顺序展开。右表所有列保留，同名列使用 `表ID__列名`，继续冲突则添加前导下划线。

| 字段          | 定义                                 |
| ------------- | ------------------------------------ |
| leftBefore    | 步骤前左表记录数                     |
| matchedLeft   | 至少匹配一条右表记录的左表记录数     |
| unmatchedLeft | 没有匹配的左表记录数，含缺失键       |
| droppedLeft   | 内连接移除的左表记录；左连接为 0     |
| addedRows     | 一对多展开额外产生的记录数           |
| outputRows    | leftBefore − droppedLeft + addedRows |
| unusedRight   | 清洗后未使用的右表记录数             |

两侧未匹配记录保存于 `unmatched.json`。多次连接后的左侧来源记录之前的全部输入表，不能把当前序号当作原始记录号。重复键错误的简短样例只引用其标注的来源表。

## 面板检查

检查四位年度值（1800–2200）及非空实体。重复实体 × 年份按组计数，不删除。每个实体的缺口只计算其自身最小年和最大年之间，不假设相同观察窗口。缺口样例有限，总数完整。

重复、缺口和无效年度是可导出的警告；违反方案约束或计算失败是阻止导出的错误。程序不检验因果识别、代表性、统计口径或单位的经济含义。

## 复现的范围

输入快照保留解析后的文本与原始逻辑记录号，不包含上传文件的原始字节。查看用 CSV 已规范化，不能用于验证原文件摘要；请另外保留原文件。

Python 校验 `parsed-inputs.json`、`plan.json`、`expected.json` 摘要，独立执行并比较列顺序、值、来源、样本变化、清洗日志与面板统计。失败返回非零退出码；输出目录存在时拒绝覆盖。不复制期望结果，不调用模型。

摘要用于发现意外变更；同时修改数据和清单仍可改变整个包，不构成签名。独立实现一致也不是对所有输入的正确性证明。测试涵盖合成企业示例、空白与全空记录、十进制数、去重和多次连接、数字列名、原型字段名、非法方案以及 HTML / CSV 文本处理。欢迎贡献最小匿名案例。
